# tender-chat

Tender quotation editor. A contractor signs in with Google, opens a tender, picks a company, a Hindi layout and a font, fills the placeholder form, edits the live A4 preview and downloads the quotation PDF.

See `PROJECT-PLAN.md` for the scope and build rounds, and `CLAUDE.md` for how to run and check the project.

```sh
pnpm install
pnpm dev
```
